Explicando código hecho en lenguaje C

El código que nos dan es el siguiente:

        
            #include <stdio.h>
            int main() {
            int edad;
            printf("¿Cuántos años tienes? ");
            scanf("%d", &edad);

            if (edad >= 18) {
                printf("Eres mayor de edad.\n");
            } else {
                printf("Eres menor de edad.\n");
            }

            return 0;
            }

La línea #include <stdio.h> sirve para incluir la biblioteca estándar de entrada y salida, la cual permite usar funciones como printf y scanf.

La función int main() es la función principal del programa.

La instrucción int edad; declara una variable llamada edad, la cual almacenará el número que ingrese el usuario.

La función printf("¿Cuántos años tienes? "); muestra un mensaje en pantalla para pedir la edad del usuario.

La instrucción scanf("%d", &edad); permite capturar el dato que escribe el usuario y guardarlo en la variable edad.

La linea if (edad >= 18) verifica si la edad es mayor o igual a 18. Si la condición es verdadera, se muestra el mensaje "Eres mayor de edad".

Else se ejecuta cuando la condición anterior no se cumple. En este caso, muestra el mensaje "Eres menor de edad".

Finalmente, return 0; indica que el programa terminó correctamente.
